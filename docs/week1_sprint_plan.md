| `request_time` | datetime（UTC） | 求助时间 |
| `request_text` | str | 求助原文 |
| `reply_id` | int64 | 品牌首次直接回复的 `tweet_id` |
| `reply_time` | datetime（UTC） | 回复时间 |
| `reply_text` | str | 回复原文 |
| `wait_min` | float64 | 等待时间（分钟） |
| `hour_utc` | int | 求助时间的 UTC 小时，0–23 |
| `weekday` | int | 星期几，0 为周一，6 为周日 |

| 列名 | 类型 | 说明 |
|---|---|---|
| `case_id` | int64 | 主键，与案例表一致 |
| `lang` | str | 语言检测结果 |
| `in_en_sample` | bool | 是否属于英文随机样本 |

| `labels` | list[str] | 问题类别（多标签） |
| `reply_type` | str | `public` / `dm` / `template` |

## 7 工作规范

本周执行章程第 10 节的协作机制，重点如下：

目录职责、个人 notebook 与 `notebooks/main.ipynb` 的集成、分支和 Pull Request 操作流程见 [CONTRIBUTING.md](../CONTRIBUTING.md)。
